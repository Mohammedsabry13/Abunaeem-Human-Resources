# Abunaeem — Human Resources Corporate Website

A professional corporate website for **Abunaeem Human Resources**, an Alexandria-based recruitment and HR services company operating across Egypt, Romania, and Italy. Founded in 2025.

---

⚠️ This template was originally created by Mohammed Sabry
If you use this, credit is required.

## 🛠️ Tech Stack

- **HTML5 & CSS3** — semantic structure and custom styling
- **Bootstrap 5.3** — responsive grid, offcanvas mobile menu
- **WOW.js + Animate.css** — scroll-triggered animations
- **Bootstrap Icons & Font Awesome 6.7** — dual icon sets
- **Plus Jakarta Sans** — Google Fonts typography
- **Vanilla JavaScript** — modal popup, form handling, WOW init

## ✨ Features

- Fullscreen hero section with 3-slide background carousel
- Hero slide counter with up/down navigation arrows
- Hero social media icons sidebar (desktop)
- Sticky navbar with Bootstrap offcanvas mobile menu
- About Us, Services & Industries sections
- Contact & inquiry form with Subject field
- Floating WhatsApp button linked to real number
- Certificate/document popup modal
- Footer with multi-city office locations (Alexandria, Milan, Bucharest)
- Fully responsive across all screen sizes
